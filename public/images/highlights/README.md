# Workshop highlight photos

Drop workshop photographs in this folder, then list them in
`src/data/highlights.ts` to have them appear in the hero gallery.

- **Format:** WebP preferred (JPEG works too)
- **Shape:** landscape, around 1600px wide
- **Size:** aim for under ~300KB each so the page stays fast

Run `npm run images:optimize` after adding JPEGs to generate WebP versions.
